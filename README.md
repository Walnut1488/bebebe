# Эмулятор командной строки UNIX-подобной ОС (Вариант №15)

Практическая работа по курсу «Конфигурационное управление» (УНБО-04-25,
РТУ МИРЭА). Эмулятор языка оболочки: консольный REPL с настраиваемыми
параметрами запуска и виртуальной файловой системой (VFS), которая
загружается из CSV-файла и живёт только в оперативной памяти.

## 1. Общее описание

Программа имитирует работу в командной строке UNIX-подобной ОС:

- запускается как консольное приложение (CLI) и в цикле читает команды
  пользователя (REPL — read-eval-print loop);
- поддерживает настройку через параметры командной строки и «стартовый
  скрипт» — файл с заранее записанными командами;
- умеет загружать виртуальную файловую систему (VFS) из CSV-файла в
  память, не изменяя исходный файл на диске.

Работа ведётся поэтапно; статус этапов — ниже.

## 2. Этапы и статус

- [x] Этап 1 — REPL: консольный интерфейс, парсер команд, команды-заглушки
      `ls`/`cd`, команда `exit`.
- [x] Этап 2 — конфигурация: параметры командной строки, отладочный вывод
      параметров, выполнение стартового скрипта с остановкой на ошибке.
- [x] Этап 3 — VFS: загрузка VFS из CSV в память, обработка ошибок
      загрузки, тестовые VFS разного размера и вложенности.
- [ ] Этап 4 — реальная логика `ls`/`cd`, команды `date`, `find`.
- [ ] Этап 5 — команды `cp`, `touch` (изменение VFS в памяти).

## 3. Структура репозитория

```
.
```

## 4. Описание функций и настроек

### Параметры командной строки

| Параметр      | Назначение                                      | По умолчанию |
|---------------|--------------------------------------------------|--------------|
| `--vfs-path`  | путь к CSV-файлу с описанием VFS                  | не задан     |
| `--prompt`    | приглашение к вводу, отображаемое в REPL          | `myvfs`      |
| `--script`    | путь к стартовому скрипту с командами эмулятора   | не задан     |

При запуске программа печатает отладочную информацию обо всех заданных
параметрах, а затем (если указан `--vfs-path`) — результат загрузки VFS:
количество папок/файлов и дерево структуры, либо понятную ошибку, если
файл VFS не найден или повреждён.

### Команды REPL

- `ls [аргументы]` — на данном этапе заглушка: печатает свои аргументы.
  Логика поверх VFS появится на Этапе 4.
- `cd [аргументы]` — на данном этапе заглушка, аналогично `ls`.
- `exit` — завершить работу эмулятора.
- Неизвестная команда не приводит к падению программы — печатается
  сообщение `<команда>: команда не найдена`.

### Стартовый скрипт

Текстовый файл с командами эмулятора, по одной на строку. Выполняется
построчно при запуске: каждая строка сначала печатается вместе с
приглашением (имитация ввода пользователя), затем выполняется.
Выполнение останавливается на первой команде, завершившейся ошибкой.

### Формат CSV для VFS

```
path,type,content
/docs,dir,
/docs/readme.txt,file,<base64>
```

- `path` — абсолютный путь элемента внутри VFS;
- `type` — `dir` для папки или `file` для файла;
- `content` — для файлов содержимое, закодированное в base64 (используется
  для хранения произвольных, в том числе двоичных, данных); для папок — пусто.

Родительская папка элемента должна быть описана в CSV раньше самого
элемента. Вся VFS хранится только в памяти — исходный CSV-файл не
изменяется и не распаковывается на диск.

## 5. Сборка, запуск и тесты

Запуск эмулятора через единую точку входа:

```bash
./run.sh --vfs-path vfs_examples/nested.csv --prompt student15
```

Запуск без параметров (используются значения по умолчанию):

```bash
./run.sh
```

Запуск модульных тестов:

```bash
python3 -m unittest discover -s tests
```

Повторная генерация тестовых CSV-файлов VFS (если нужно пересоздать
`vfs_examples/`):

```bash
python3 build_vfs_examples.py
```

## 6. Примеры использования

Запуск с кастомным приглашением:

```
$ ./run.sh --prompt student15
=== Параметры запуска эмулятора ===
  Путь к VFS:        None
  Приглашение:       student15
  Стартовый скрипт:  None
====================================
student15> ls
ls: аргументы = []
student15> exit
```

Запуск с подключённой VFS (вложенность 3+ уровня):

```
$ ./run.sh --vfs-path vfs_examples/nested.csv
=== Параметры запуска эмулятора ===
  Путь к VFS:        vfs_examples/nested.csv
  ...
VFS загружена успешно: 3 папок, 3 файлов
Структура VFS:
└── docs/
    ├── images/
    │   ├── icons/
    │   │   └── star.png (40 байт)
    │   └── logo.png (40 байт)
    └── readme.txt (39 байт)
myvfs>
```

Обработка ошибки загрузки VFS (CSV с файлом без папки-родителя):

```
$ ./run.sh --vfs-path vfs_examples/broken.csv
...
Ошибка загрузки VFS: строка 2: папка '/missing' не найдена — родитель
для '/missing/orphan.txt' должен быть описан раньше в файле
Эмулятор продолжит работу без VFS.
```

Больше готовых сценариев — в файлах `run_default.sh`, `run_custom_prompt.sh`,
`run_with_script.sh`, `run_with_error_script.sh`, `run_vfs_minimal.sh`,
`run_vfs_several_files.sh`, `run_vfs_nested.sh`, `run_vfs_broken.sh`.
